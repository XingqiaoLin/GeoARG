When the user asks to find novel antimicrobial resistance genes after a date, to cross-check preprints against formal papers, or to confirm that a resistance gene was experimentally validated, use the `novel-arg-watch` skill.

All skill files: `skills/novel-arg-watch/`

To load it as an installed skill, run `python skills/novel-arg-watch/scripts/install.py --codex` (or `--cursor`), which copies the folder to `~/.codex/skills/novel-arg-watch/` or `.cursor/skills/novel-arg-watch/`.

Verify before a live search:

```bash
python skills/novel-arg-watch/scripts/verify.py
```
